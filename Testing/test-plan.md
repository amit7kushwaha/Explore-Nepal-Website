Pabitra's Test Plan — REQ-3 and REQ-10

1. Introduction

This test plan describes the testing activities for the requirements assigned to Pabitra in the Explore Nepal Travel & Tourism Website.

2. Testing Objectives

- Verify destination details are displayed correctly.
- Verify available travel information is displayed.
- Verify visitors can submit travel inquiries.
- Verify inquiry information is stored correctly.
- Verify administrators can view and manage inquiries.

3. Scope of Testing

REQ-3: View Destination Details & Travel Information

Testing includes:

- Destination name and location.
- Destination description and highlights.
- Destination images.
- Available travel information and advisories.

REQ-10: Inquiry Management

Testing includes:

- Inquiry form submission.
- Input validation.
- Inquiry data storage.
- Administrator inquiry viewing.
- Inquiry status updates.

4. Testing Method

Manual testing will be performed through the website interface.

5. Test Environment

- Operating System: Windows
- Programming Language: Python
- Framework: Django
- Browser: Google Chrome
- Database: Database configured in the Django project.

6. Entry Criteria

- Required application features are implemented.
- Django development server can run.
- Required test data is available.

7. Exit Criteria

- All planned test cases have been executed.
- Test results are recorded.
- Identified issues are documented.

8. Expected Outcome

The destination information and inquiry management features should work according to the assigned requirements.

9. Conclusion

This test plan provides a structured approach to testing REQ-3 and REQ-10 of the Explore Nepal Travel & Tourism Website.
