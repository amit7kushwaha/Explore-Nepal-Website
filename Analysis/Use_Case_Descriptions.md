Use Case Descriptions

REQ-1: Browse Destinations

Actor: Visitor

Visitor opens the website.

System displays featured Nepal destinations.

Visitor selects a destination.

System shows destination details.

REQ-6: Admin Login

Actor: Admin

Admin opens the login page.

Admin enters username and password.

System verifies the details.

If valid, admin gets access to the dashboard.

If invalid, an error message is displayed.
