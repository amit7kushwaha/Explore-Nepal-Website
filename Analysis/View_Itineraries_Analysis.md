# REQ-4: View Itineraries

1. Purpose
Allow website visitors to browse and read suggested travel itineraries in Nepal, including trip highlights and regional details.

2. User Requirements
- Visitors can see a list of available travel itineraries (e.g., Kathmandu Tour, Pokhara Trip, Everest Trek).
- Visitors can click on an itinerary to read the day-by-day schedule (Day 1, Day 2, etc.).
- Visitors can see the trip duration, destination region, and main highlights.
- No login is required to view itineraries.
