# REQ-4: View Itineraries — Design

## 1. Page Layout (UI Design)
- **Header:** Navigation bar with links (Home, Destinations, Itineraries, Transport & Accommodation, Inquiry).
- **Itinerary List Section:** A grid of cards showing each Nepal trip with:
  - Trip Photo
  - Trip Title (e.g., "3-Day Pokhara Scenic Getaway")
  - Region & Duration (e.g., "Gandaki Province • 3 Days")
  - Short Summary & "View Details" Button
- **Itinerary Detail View:** When a visitor clicks "View Details", it shows:
  - Full Trip Highlights
  - Day-by-Day Schedule (Day 1, Day 2, Day 3...)

## 2. Itinerary Information Structure
Each itinerary will include:
- **Title:** Name of the trip
- **Region:** Area in Nepal (e.g., Kathmandu, Pokhara, Everest, Chitwan)
- **Duration:** Number of days
- **Highlights:** Key attractions included
- **Daily Plan:** Step-by-step schedule for each day
